# Obsidian 知识库管理方法

## 文件夹结构

```
obsidian-vault/
├── README.md           # 本文件（管理方法说明）
├── Attachments/        # 图片、PDF 等附件
├── Templates/          # 笔记模板
├── References/         # 长期参考材料
├── Projects/           # 项目相关笔记
├── Learning/           # 学习笔记、知识整理
├── claude-memory/      # Claude Code 全局记忆
└── Inbox/              # 待整理笔记
```

## 分类原则

| 文件夹 | 用途 | 示例 |
|--------|------|------|
| Inbox/ | 新笔记先放这里，定期整理 | 临时想法、快速记录 |
| Projects/ | 具体项目相关 | 项目笔记、进度追踪 |
| Learning/ | 学习笔记、知识整理 | 读书笔记、课程记录 |
| References/ | 长期参考（方法、原则、最佳实践）| 工作流、规范、模板 |
| Templates/ | 笔记模板 | 日报模板、会议记录模板 |
| Attachments/ | 图片、PDF 等附件 | 截图、文档 |
| claude-memory/ | Claude Code 全局记忆 | 跨会话持久化配置 |

## 核心原则

1. **根目录保持简洁** - 只放 README.md
2. **Inbox 先行** - 新笔记先进 Inbox，定期归档
3. **极简分类** - 避免过度分类，够用即可

## 关系图谱（Graph View）

### 原理

关系图谱显示笔记之间的链接关系。**有链接才有连线**，没有相互链接的笔记在图谱中看不到连接。

### 如何打开

左侧工具栏（Ribbon）点击 **"打开关系图谱"** 图标（网络图图标）

### 如何创建内部链接

在笔记中输入 `[[笔记名称]]` 即可创建链接：

```markdown
# 示例
今天学到了[[思维模型]]的概念...
参考[[深度思考方法]]了解更多...
```

**快捷键**：输入 `[[` 后自动弹出笔记列表，选择即可

### 链接语法

| 语法 | 效果 |
|------|------|
| `[[笔记名]]` | 链接到整篇笔记 |
| `[[笔记名#标题]]` | 链接到特定标题 |
| `[[笔记名#标题#子标题]]` | 链接到嵌套标题 |
| `[[笔记名|显示文字]]` | 自定义显示文字 |

### 图谱操作

- **悬停** - 高亮该笔记的所有连接
- **点击** - 打开该笔记
- **右键** - 显示更多操作
- **滚轮** - 缩放
- **拖动** - 移动图谱

### 图谱设置（左上角齿轮）

- **Filters** - 过滤显示哪些笔记
- **Orphans** - 显示孤立笔记（无链接的笔记）
- **Groups** - 按颜色分组

### 常见问题

**问题：图谱中看不到连线**

原因：笔记之间没有相互链接

解决：在笔记中添加 `[[其他笔记名]]` 链接
