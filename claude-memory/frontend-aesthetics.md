# 前端美学原则

避免"AI 泛滥"美学，制作有创意、独特的前端。

## 重点关注

- **排版**：选择美观、独特且有趣的字体。避免 Arial、Inter 等通用字体。
- **颜色和主题**：坚持一致的美学，使用 CSS 变量。主色调配以鲜明的强调色。从 IDE 主题和文化美学中汲取灵感。
- **动效**：使用动画实现效果和微交互。HTML 优先用纯 CSS；React 用 Motion 库。专注于高影响力的时刻（如精心编排的页面加载配合交错显示）。
- **背景**：创造氛围和深度，而非纯色。叠加 CSS 渐变、几何图案或上下文效果。

## 避免通用 AI 生成美学

- 过度使用的字体（Inter、Roboto、Arial、系统字体）
- 陈词滥调的配色（特别是白色背景上的紫色渐变）
- 可预测的布局和组件模式
- 缺乏上下文特定特征的千篇一律设计

## 跳出框框思考

创造性地解读，做出意想不到的选择。在浅色/深色主题、不同字体、不同美学之间变化。避免收敛到常见选择（如 Space Grotesk）。
