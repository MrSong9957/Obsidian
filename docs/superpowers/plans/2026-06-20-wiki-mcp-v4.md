## Task 2: core::patch(section 级编辑)

**Files:** `core.rs`

- [ ] **Step 1: 写 patch 函数(失败测试先行)**

在 core.rs 加 `patch` 函数。逻辑:
1. `policy::check(path, Op::Write)?`
2. 读文件 `read_to_string`(不存在 → NotFound)
3. `frontmatter::parse` 拆 frontmatter + body
4. 在 body 里定位 heading 行(`## {heading}` 或 `### {heading}`)
5. heading 不存在 → `Err(WikiError::NotFound(format!("heading '{}' 不存在", heading)))`
6. section 范围:heading 行下一行 到 下一个同级或更高级 heading 前
7. 替换 section 内容为 new_content(保留 heading 行本身)
8. `frontmatter::serialize` 重组 + 写回 + `sync_file_by_path`

heading 定位辅助函数(纯函数,易测):
```rust
/// 在 body 中找 `## {heading}` 或 `### {heading}` 的行号。
/// 返回 (heading 行号, section 结束行号:下一个同级或更高级 heading 前)。
/// heading 不存在返回 None。
fn locate_section(body: &str, heading: &str) -> Option<(usize, usize)>
```

- [ ] **Step 2: 写 locate_section 单元测试**

纯函数测试,覆盖:
- h2 heading 存在
- h3 heading 存在
- heading 不存在 → None
- 文档末尾的 section(无下一个 heading)
- 同名 heading 取第一个

- [ ] **Step 3: 写 patch 集成测试**

在 core_write_test.rs 加:
- patch 替换某 section → 读回验证内容变了
- patch 不存在 heading → NotFound 错误
- patch 后即时索引(search 能搜到新内容)
- patch templates/ → policy 拒绝

- [ ] **Step 4: 运行测试**

`cargo test patch` + `cargo test --test core_write_test`

## Task 3: MCP wiki_patch 工具 + ServerInfo instructions

**Files:** `mcp_server.rs`, `tests/mcp_integration_test.rs`

- [ ] **Step 1: 改 mcp_server 为手动 ServerHandler 模式**

参考 rmcp counter 示例。改动:
1. `WikiServer` struct 加 `tool_router: ToolRouter<WikiServer>` 字段
2. `#[tool_router]`(去掉 `server_handler` 参数)
3. 加 `pub fn new(vault_root: String) -> Self` 初始化 tool_router
4. 手写 `impl ServerHandler for WikiServer`:
   - `get_info` 返回带 instructions 的 ServerInfo(三层结构 + 四态 + 工具列表)
   - `list_tools` 等委托 `self.tool_router.inner_list_tools` 等(参考 counter 的委托写法,或用 rmcp 提供的默认委托)
5. `run()` 里 `WikiServer { vault_root, tool_router: ... }` → `WikiServer::new(vault_root)`

import 调整:加 `ToolRouter`, `ServerHandler`, `ServerInfo`, `ServerCapabilities`, `Implementation` 等。

- [ ] **Step 2: 加 wiki_patch MCP 工具**

在 `#[tool_router]` impl 里加:
```rust
#[tool(description = "局部编辑文档的某个 section(按 heading 切分替换),避免整篇重写。参数 path 文档路径,heading 要编辑的标题(## 或 ###),new_content 新内容。heading 不存在返回错误。")]
fn wiki_patch(&self, Parameters(req): Parameters<PatchRequest>) -> Result<CallToolResult, McpError> {
    match core::patch(&self.vault_root, &req.path, &req.heading, &req.new_content) {
        Ok(()) => Ok(CallToolResult::success(vec![Content::text("section 已更新".into())])),
        Err(e) => err_to_result(e),
    }
}
```

加 `PatchRequest { path, heading, new_content }` 结构体(schemars JsonSchema)。

- `mcp_initialize_has_instructions`:initialize 响应含 instructions 文本
- `mcp_tools_list_exposes_wiki_patch`:tools/list 含 wiki_patch
- (可选)wiki_patch 可调用
