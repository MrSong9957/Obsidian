# 规格：短链接服务（重建样例）

- 状态：待实现
- 更新时间：2026-10-24
- 样例说明：旧样例和旧证据已丢失。本规格按《规格文档实战法》重建，用于 2026-10-24 的新一轮盲测；它不是旧规格原文，也不能当作旧结果。

## 1. 要做什么，有哪些要求

- 功能：创建短链接、查询统计、访问跳转。只做这三个接口，不做登录、删除、管理页面或外部网络调用。
- 启动：读环境变量 `PORT` 和 `DB_PATH`；`PORT=0` 表示由系统分配端口。启动成功后向 stdout 打印一行 `listening on http://127.0.0.1:<实际端口>`，并立即刷新。DB 文件不存在时自动创建，父目录不存在时也创建。
- 存储：使用 SQLite，数据落盘；服务重启后，链接和点击数必须还在。创建接口返回 201 前必须已经提交，不能只放内存。被测服务只允许一个进程；可以用线程，但不能用多进程规避 10 MiB 内存上限。收到 SIGTERM 后 5 秒内退出，已提交的数据必须保留。
- HTTP：支持 HTTP/1.1 keep-alive；响应必须有正确的 `Content-Length`；不要求 chunked。
- 编码：请求和响应用 UTF-8。成功响应 `Content-Type: application/json; charset=utf-8`。

### 1.1 创建短链接

`POST /api/links`

- 要求 `Content-Type` 的媒体类型为 `application/json`（大小写不敏感，可带 `; charset=utf-8`）。请求体是 JSON 对象，最多 1 MiB；超过 1 MiB 返回 `400 {"error":"invalid_request"}`，不能崩溃；多出的字段忽略。
- 字段：
  - `url`：必填，字符串，长度按 UTF-8 字节数计 1–2048。只接受 `http://` 或 `https://`，必须有主机名；不能含 ASCII 控制字符（0x00–0x1F、0x7F）；scheme 和主机名里不能有空格；路径、查询、片段里的普通空格允许，并按第 1.3 节编码。URL 中的 `%` 必须紧跟两个十六进制数字；否则按非法 URL 处理。
  - `alias`：可选，字符串，4–32 个字符，只允许 `A-Z a-z 0-9 _ -`；区分大小写；`api`、`health` 两个别名保留，不能使用。`alias: null` 视为未提供。
  - `ttl_seconds`：可选，JSON 整数，范围 1–31536000；布尔值、浮点数、字符串都算非法。不传或 `null` 表示不过期。
- 成功：`201`，响应对象只含：
  - `code`：字符串；自动生成时是 7 位 `A-Z a-z 0-9`；使用别名时就是别名。
  - `short_url`：`http://127.0.0.1:<实际端口>/<code>`。
  - `expires_at`：UTC ISO 8601，精确到秒，格式 `YYYY-MM-DDTHH:MM:SSZ`；不过期为 `null`。
- 失败响应只含一个 `error` 字段：
  - `400 {"error":"invalid_request"}`：JSON 非法、请求体不是对象、`Content-Type` 不对、字段类型不对、`ttl_seconds` 越界或不是整数。
  - `400 {"error":"invalid_url"}`：URL 不符合上面的规则。
  - `400 {"error":"invalid_alias"}`：别名不符合规则或是保留字。
  - `409 {"error":"alias_taken"}`：别名已存在。
- 自动生成的短码必须唯一；同一 URL 创建两次应得到两个不同短码。
- 时间统一用 Unix 秒，向下取整；有 TTL 时 `expires_at = created_at + ttl_seconds`。`expires_at <= 当前时间` 即过期。

### 1.2 查询统计

`GET /api/links/<code>`

- 存在且未过期：`200`，响应对象只含 `code`、`url`、`clicks`、`created_at`、`expires_at`、`expired`。
  - `clicks` 是非负整数；`created_at` 和 `expires_at` 格式同上，`expires_at` 可为 `null`。
  - `expired` 是布尔值；正好到期时算已过期。
- 已过期：仍然 `200`，`expired` 为 `true`，`clicks` 保持过期前的值。
- 不存在：`404 {"error":"not_found"}`。

### 1.3 跳转

`GET /<code>`

- 存在且未过期：`302`，`Location` 为原始 URL 的编码结果，`Content-Length: 0`；成功后该短码的 `clicks` 正好加 1。
- 已过期：`410 {"error":"expired"}`，点击数不能再增加。
- 不存在：`404 {"error":"not_found"}`。
- `Location` 编码规则：
  - 原 URL 中已有的 `%HH` 三元组必须原样保留，大小写也不能变。
  - ASCII 保留字符 `:/?#[]@!$&'()*+,;=` 和非保留字符 `A-Z a-z 0-9 - . _ ~` 保持原样；空格、非 ASCII、控制字符和其他不安全字节按 UTF-8 百分号编码。
  - 例如输入 `https://example.com/a%2Fb?x=%20&y=1`，`Location` 必须完全相同；输入 `https://example.com/路径?x=中 文#片段`，`Location` 必须为 `https://example.com/%E8%B7%AF%E5%BE%84?x=%E4%B8%AD%20%E6%96%87#%E7%89%87%E6%AE%B5`。
  - 验收直接比较原始响应头，不允许“先解码一次再比较”的写法。

### 1.4 测试条件、速度和资源

- 环境：Linux x86_64 WSL2，16 vCPU，约 15.5 GiB 内存；服务端和压测客户端是两个独立进程；本机 `127.0.0.1`；不访问外网。
- 语言与工具：只允许 Rust 1.99（可用本机离线 crate 缓存）或 C11（SQLite 动态库在 `/lib/x86_64-linux-gnu/libsqlite3.so.0`）。不允许 Python 作为服务端，因为 Python 解释器本身已接近 10 MiB。
- 预置数据：压测前先创建 1000 条链接，短码 `seed0001`–`seed1000`，URL 为 `https://example.com/seed/<短码>`。
- 跳转压测：50 个并发客户端，每轮 500 次请求（每客户端 10 次），先预热 50 次；共 3 轮。p95 按最近秩计算，取 3 轮 p95 的中位数。
- 创建压测：50 个并发客户端，每轮 100 次请求（每客户端 2 次），先预热 20 次；共 3 轮，取 3 轮 p95 的中位数。每轮使用不同 URL。
- 内存：压测结束后读服务进程 `/proc/<pid>/status` 的 `VmHWM`，上限 10 MiB（10240 KiB）。被测服务只有一个进程；客户端进程不计。
- 要求：在上述条件下，跳转 p95 ≤ 10.00ms，创建 p95 ≤ 15.00ms，服务进程 VmHWM ≤ 10 MiB。没有预热、轮次或结果选取方式的数据不算通过。
- 费用：功能本身没有外部付费调用；本次测试的模型用量由运行平台记录。拿不到用量就写“未测”，不能写成 0。

## 2. 哪些情况容易出错

- 同一别名并发创建：只能 1 个 201，其余 409；不能出现两个同名链接。
- 同一短码 50 并发跳转：点击数必须正好增加 50；不能丢计数或重复计数。
- TTL 到期：用 1 秒 TTL 等待到期，跳转 410，统计 200 且 `expired=true`，点击数不变；不能靠直接改数据库凑边界。
- 重启：创建、跳转几次后停掉服务，用同一个 `DB_PATH` 重启；链接、点击数和过期时间都要保留。
- 编码：已有 `%2F`、小写 `%2f`、`%20` 必须原样保留；中文、空格要按 UTF-8 编码；不能用解码一次后的字符串做比较。
- 非法输入：坏 JSON、缺 `Content-Type`、非对象、布尔/浮点 TTL、超长 URL、scheme/host 带空格、含控制字符的 URL、非法别名、保留别名、重复别名、未知短码。路径里的普通空格是合法的，要编码。
- 别名大小写：`Abc1` 和 `abc1` 是两个不同链接。
- 服务启动：`PORT=0` 时要用实际端口生成 `short_url`；启动行必须能读到。
- 数据量变大：1000 条预置数据后仍要满足速度和内存上限。
- 并发写数据库：不能因为锁冲突返回 500，也不能让点击数少于实际成功跳转数。

## 3. 重要做法，为什么这样做

- 别名唯一：用数据库主键/唯一约束兜底，不能只靠“先查再插”，否则并发会双写。
- 点击数：用一条原子更新同时判断过期并自增（例如 `UPDATE ... WHERE code=? AND (expires_at IS NULL OR expires_at > ?) RETURNING ...`），避免先读后写丢计数。
- 过期：所有时间用整数 Unix 秒；`expires_at <= now` 算过期。写清“正好到期”算过期，避免边界不一致。
- SQLite：启用 WAL 和 `busy_timeout`；创建成功返回前必须提交。读多写少时 WAL 能减少锁等待。
- 内存：固定大小的工作线程池和有限队列，避免每个连接都创建大栈线程；不要一次性把全部链接读进内存。50 并发下也要守住 10 MiB。
- 编码：按字节保留已有 `%HH`，只对不安全字节做 UTF-8 百分号编码；不要先 `unquote` 再 `quote`，否则 `%2F` 会变成 `/`。
- 启动：先绑定端口，拿到实际端口后再生成 `short_url` 和打印启动行，避免 `PORT=0` 时写错端口。
