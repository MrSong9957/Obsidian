## 十个提升生产力的 CLI 工具推荐

1. **Collie Anything** — 工具的工具，帮你生成其他 CLI 工具的神器
2. **LLM is Simon Wilson** — 帮你选择合适电脑配置的本地 AI 模型
3. **NotebookLM CLI** — 打通谷歌 NotebookLM 的 CLI 工具（无公开 API 情况下）
   - 功能：输入 YouTube 视频链接，AI 分析内容，利用谷歌免费服务器处理数据，批量生成博客、PPT、信息图、测验题、学习卡片、支持批量下载和程序化分享（网页版不具备的功能）
4. **FFmpeg** — 视频剪辑、格式转换、音频处理的全能工具
5. **GitHub CLI** — 终端内完成所有 GitHub 操作，无需打开网页
6. **Vercel CLI** — 一条命令将网站或应用部署到互联网
7. **Supabase CLI** — Firebase 的开源平替，让 Claude Code 直接管理数据库和用户系统
8. **Stripe CLI** — 简化 Stripe 支付平台操作，无需打开多个网页标签
9. **Google Workspace CLI** — 让 Claude Code 接管 Gmail/Google Docs/Google Sheets 等谷歌生态
10. **Playwright CLI** — 让 Claude Code 自动打开浏览器测试网页应用
