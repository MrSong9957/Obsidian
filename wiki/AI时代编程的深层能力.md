# AI 时代编程的深层能力

> 核心训练的是“自己设计，AI 查零件”

学习方法可以压缩成一句话：

> **自己负责“想清楚程序怎么工作”，AI 负责“帮你查具体 API 怎么写”。**

具体练习按这 5 步：

1. **先自己拆流程**
   先写自然语言注释，不急着写代码。

   ```rust
   // 读取 API Key
   // 构造请求
   // 发送请求
   // 检查 HTTP 错误
   // 解析 JSON
   ```

2. **自己写骨架和关键逻辑**
   函数怎么分、数据怎么流、错误怎么处理，尽量自己决定。

3. **不会 API 就查，不硬背**
   问 AI 或查 docs.rs：
   “reqwest 检查 4xx/5xx 用什么方法？返回什么？”

4. **AI 生成后必须看懂**
   至少能解释：

   * 输入是什么
   * 返回什么
   * 为什么放这里
   * 出错会怎样

5. **定期空白重写**
   过几天不看原代码，重新实现一次。
   可以查 API，但不让 AI 直接写完整答案。

最终目标不是：

> “我能背出所有 API。”

而是：

> **“不给我代码，我也知道应该怎么设计；具体 API 忘了，我能快速查出来。”**

这条路线最适合从 Level 3–4 往 Level 5–6 练。

Level 1
这段代码我大概看得懂

Level 2
每一行输入输出我都知道

Level 3
让我修改它，我知道改哪里

Level 4
它坏了，我能定位原因

Level 5
不给我这份代码，我也知道大概应该怎样设计

Level 6
我能判断还有没有更好的设计
