# 学习方法

## 核心学习方法：学霸七法（熊子骁）

> 14岁考入西交少年班、19岁直博清华。七条核心策略 ← [[sources/learning/learning-references.md]] L433-490

1. **框架学习法**：先搭建学科整体框架，再填充知识点——先有地图再走迷宫
2. **反向解题法**：从"考什么"出发定位考点，而非从条件硬推——以终为始
3. **深层理解法**：提炼题目核心脉络，不只套公式——理解逻辑才能举一反三
4. **逻辑式习惯**：多问"为什么"和"有什么关联"，串联碎片化知识——编织知识网络
5. **分科目策略**：理科抓核心万变不离其宗，文科多感官记忆——因科施法
6. **渐进式计划**：从简单任务起步逐步加难，靠正向反馈养成习惯——避免详细计划一旦打断全盘崩溃
7. **题海战术观**：先理清规则脉络再刷题，理解 > 数量——掌握题型后换思路验证

**核心思想**：框架优先 → 深层理解 → 逻辑串联 → 渐进练习

与螺旋上升学习法互补——框架学习法提供内→外的全局观，渐进计划提供外→内的正向反馈循环。

## 认知学习编程法

> **vibe coding = 你描述结果，AI 完成一切。**
> **认知学习 coding = 你描述过程，AI 执行步骤。**

区别在于：你是**导演**还是**观众**。导演不需要亲自演戏，但必须知道每场戏要什么效果、为什么这样演、哪里不对怎么调。

**铁律：AI 代替打字可以，但不能代替思考。禁止跳过认知过程。**

核心原则是四层认知分离——**设计 vs 打字、验证 vs 实现、诊断 vs 修复、决策 vs 评估**：人始终负责设计、验证、诊断、决策，AI 只负责执行。

具体的编程能力训练流程已收敛至 **[[AI时代编程的深层能力]]**（五步练习：自己拆流程→写骨架→查 API 不硬背→读懂 AI 生成→定期空白重写），本页不再维护平行训练流程；四层分离法详解见 [[learning-references]]。

## 六大认知提升习惯

1. **深度思考**：每日 15-30 分钟无设备干扰，激活默认模式网络
2. **主动探索**：先独立思考再求助，长期记忆留存率高 40%
3. **为思考而写**：思考日记聚焦"理解/困惑/未成形想法"
4. **构建思维模型**：每周学 1-2 个跨学科模型并尝试应用
5. **记忆力训练**：间隔重复法（Anki）+ 记忆宫殿技巧
6. **保护认知精力**：7-9 小时睡眠 + 番茄工作法 + 运动

**核心洞察**：习惯的复利效应——坚持 6 个月，流体智力可提高 7-12 分

## 学习路径结论

- **两条路径**：内→外（基础到应用）和外→内（实践到原理），各有致命缺陷
- **螺旋上升**是真正有效的模式——交替使用两条路径，每轮深入一层
- **诊断卡点**："不知道怎么做"缺实践→外→内，"不知道为什么"缺基础→内→外
- **逆向工程** = 结构化的外→内：拿能跑的东西拆开看怎么做到的
- **教材难懂的根因**是抽象层次错配（同理心缺失），不是路径选择错误

## 技能发展框架（L1-L6）

| 层次 | 投资方向 | 核心 | 谁说的 |
|------|---------|------|--------|
| **L1 基础** | 深度理解一个技术栈 | AI 放大已有深度 | Willison, Carmack |
| **L2 验证**（最高 ROI） | 测试驱动 + 手动 QA | **练一得三：表面练测试，实际练 L1+L3+L4** | Willison, Beck |
| L3 系统 | 架构设计 + 依赖分析 | 系统思维不可替代 | Karpathy, Torvalds |
| L4 判断 | 工程决策 + 权衡取舍 | 元技能，前三层积累后的涌现 | 所有人 |
| L5 工具 | 精通 AI 编程工具 | 工具杠杆 | Altman, Yegge |
| L6 多领域 | 发展第二个深度领域 | M 型技能 | WARC, McKinsey |

### 为什么 L2 最高 ROI

- L1 是慢变量 — 深入某个框架，AI 可能三个月后写得更好
- L3 不能直接练习 — 是 L1 和 L2 的副产品
- L4 是元技能 — 不是能直接投资的东西
- **L2 练验证 = 综合练习 L1+L3+L4**，且直接决定能不能用好 AI
