# 学习习惯

## 主要学习方法：学霸七法（熊子骁）

> 14岁考入西交少年班、19岁直博清华。七条核心策略 ← [[sources/learning.md]] L433-490

1. **框架学习法**：先搭建学科整体框架，再填充知识点——先有地图再走迷宫
2. **反向解题法**：从"考什么"出发定位考点，而非从条件硬推——以终为始
3. **深层理解法**：提炼题目核心脉络，不只套公式——理解逻辑才能举一反三
4. **逻辑式习惯**：多问"为什么"和"有什么关联"，串联碎片化知识——编织知识网络
5. **分科目策略**：理科抓核心万变不离其宗，文科多感官记忆——因科施法
6. **渐进式计划**：从简单任务起步逐步加难，靠正向反馈养成习惯——避免详细计划一旦打断全盘崩溃
7. **题海战术观**：先理清规则脉络再刷题，理解 > 数量——掌握题型后换思路验证

核心思想：**框架优先 → 深层理解 → 逻辑串联 → 渐进练习**

与螺旋上升学习法互补——框架学习法提供内→外的全局观，渐进计划提供外→内的正向反馈循环。

## 辅助学习方法

### 学习路径结论

- 两条路径：内→外（基础到应用）和外→内（实践到原理），各有致命缺陷
- 螺旋上升是真正有效的模式——交替使用两条路径，每轮深入一层
- 诊断卡点："不知道怎么做"缺实践→外→内，"不知道为什么"缺基础→内→外
- 逆向工程 = 结构化的外→内：拿能跑的东西拆开看怎么做到的
- 教材难懂的根因是抽象层次错配（同理心缺失），不是路径选择错误

### 六大认知提升习惯

1. **深度思考**：每日 15-30 分钟无设备干扰，激活默认模式网络
2. **主动探索**：先独立思考再求助，长期记忆留存率高 40%
3. **为思考而写**：思考日记聚焦"理解/困惑/未成形想法"
4. **构建思维模型**：每周学 1-2 个跨学科模型并尝试应用
5. **记忆力训练**：间隔重复法（Anki）+ 记忆宫殿技巧
6. **保护认知精力**：7-9 小时睡眠 + 番茄工作法 + 运动

- 核心洞察：习惯的复利效应——坚持 6 个月，流体智力可提高 7-12 分

### AI 时代语言学习哲学

以 Rust 为例得出的通用结论：

**语法表象 vs 内核哲学**
- Rust 语法近 C 系外表（花括号、分号），但所有权/借用/生命周期自成一体
- 学语言不是学语法，是学核心范式

**编译器严格性 = AI 迭代的正反馈信号**
- 强类型 + 所有权 → 编译器精确报错 → AI 据此修复 → 循环至通过
- Python 等动态语言的问题：代码能跑，但隐含内存/类型/并发错误，且无编译器告诉你
- Rust 的严格是结构优势，不是阻碍——"能编译即可靠"

**翻译路径**
- AI 翻译源码可行：人类审查核心范式，AI 处理语法和样板
- "动态语言版 Rust 编译器"不可行：语义模型存在根本矛盾
- 前提：理解目标语言的核心范式（所有权、手动内存、并发模型）

**学习方法进化**
- 传统：先系统学语法 → 再做习题 → 在 AI 时代显得低效
- AI 时代：按需学习（边写边问）→ 即时验证（编译错误贴给 AI）→ 个性化练习（AI 针对错误生成）
- 核心不变量：所有权、借用、生命周期必须亲自理解——审查 AI 代码的基石

**结论**：哲学驱动 + AI 辅助 = 未来多语言开发的主流形态。花少量时间理解核心哲学，依靠 AI 完成语法翻译，聚焦系统设计与安全审查。

## 技能发展参考

### L1-L6 行动框架

- **L1 基础**：深度理解一个技术栈，AI 放大已有深度
- **L2 验证**（最高 ROI）：练一得三——表面练测试，实际练 L1+L3+L4
- **L3 系统**：架构设计 + 依赖分析，L1/L2 的副产品，不可直接练习
- **L4 判断**：工程决策 + 权衡取舍，前三层积累后的涌现
- **L5 工具**：精通 AI 编程工具，你决定"测什么"，AI 决定"怎么写"
- **L6 多领域**：M 型技能——多领域真正深度，组合创新

### 代码讲解策略

- 底层逻辑优先，遇新概念零基础教学（生活比喻带出术语）
- 从问题出发拆解：大问题拆 2-4 个子问题，解释因果链
- 先给最直白的那句话再展开；用户反复追问 = 解释偏了
- 分析时从问题出发拆解，不从概念出发堆砌

### 编程第一性原理

- 三个张力：状态 vs 变换、结构 vs 行为、同步 vs 异步
- 五个操作：序列、选择、重复、抽象、组合
- 一个元规律：复杂度是唯一真正不可逆的敌人
